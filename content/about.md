I'm Dan Guns, a Kubernetes Platform Engineer at RBC Capital Markets, based in Halifax, Nova Scotia. My work focuses on:

- Kubernetes platform engineering and GitOps
- FluxCD — continuous delivery for Kubernetes
- Platform tooling, automation, and developer experience
- Open source contributions to the Flux ecosystem

## What I'm building

I started [flux9s](https://flux9s.ca/) because I wanted a live view of Flux resources in the terminal. It's written in Rust and inspired by k9s.

flux9s reached 1.0 in 2026, and I wrote about its development on the [Flux project blog](https://fluxcd.io/blog/2026/10/flux9s-ga/). Since then, I've added application views, mixed Flux/Kubernetes resource lists, and CPU and memory usage in the pod and node views.

I also contribute upstream to Flux and Flux Operator, including CLI improvements and ResourceSet input providers. The [open source page](/open-source/) has links to those changes.
